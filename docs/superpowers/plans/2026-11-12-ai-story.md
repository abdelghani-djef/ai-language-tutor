# AI Story Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On the Stories page, an **AI Story** button writes a short English story in the browser from 12 random
Should learn words, shows it like the ready-made stories, and offers a quiz where each story sentence is matched
to its translation.

**Architecture:** Pure, tested logic in `src/lib/ai-story.ts` (picking words, the prompt, cleaning the reply,
splitting sentences, building the quiz). A new Web Worker `src/lib/story.worker.ts` runs the Transformers.js
text-generation model, wrapped by a `useStoryWriter` hook (same pattern as the translator worker and
`useTranslator`). The page `/story/?ai=1` renders an `AiStory` component; translations come from the existing
translator (one request, one sentence per line). A `StoryQuiz` component runs the quiz.

**Tech Stack:** Next.js 16 static export, React client components, `@huggingface/transformers` 4.3.2 (already a
dependency), vitest (pure-function tests in `src/lib/__tests__`), i18n via `defineMessages` (en/fr/ar).

**Spec:** `docs/superpowers/specs/2026-11-09-ai-story-design.md`

## Global Constraints

- Free and in the browser only: no server, no API key, no online AI service.
- Static export; read `node_modules/next/dist/docs/` before writing Next.js code (AGENTS.md).
- Model: `onnx-community/Qwen3.5-0.8B-Text-ONNX`, `q4f16` on WebGPU, `q4` on WASM; fallback
  `onnx-community/Qwen3-0.6B-ONNX` (thinking off). The model actually used is decided by Task 2's gate.
- Words per story: 12 (fewer if Should learn has fewer); the AI Story button needs at least 4 Should learn words.
- Story: English, about A2, about 120–200 words, 8–14 sentences, with a title.
- Every story sentence and the title must pass `isCleanSentence` (`src/lib/word/clean.ts`); a failing story is
  rewritten once, then the learner sees a failure message with **Try again**.
- The story is not shown while it is written: "Writing your story…" with a live count of sentences written (owner-facing ruling after the gate; was words).
- Model download only after the learner agrees, with its size shown; progress bar during the download.
- Translations by the existing on-device translator (`translatorFor("en", lang)`, Opus-MT), never by the story
  model.
- Quiz: up to 8 questions; English sentence, 4 translation choices (its own plus 3 from other sentences of the
  same story). Practice only: no review, no `recordQuiz`, no badges.
- Not saved: nothing new in the store, `localStorage` data or backups.
- Labelled: "written by AI on this device, may contain mistakes"; translations are machine translations.
- All new interface text in en, fr and ar (Arabic right to left), plain style of the existing messages.
- The model code must not be in any page bundle except through the worker (`new Worker(new URL(...))`).
- Commit only when the owner asks; when committing, end messages with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never push.

## Review Focus

1. **A chat-style or list reply** ("Sure! Here's a story…", "Words used: …", markdown, `<think>` blocks): it must
   be cleaned or rejected, never shown as the story. → `cleanStory` tests (Task 1).
2. **A word in a different form** ("goes"/"went" for "go", "children" for "child", phrases like "thank you"): it
   counts as used and is highlighted, not listed as missed. → `wordsInStory` test (Task 1).
3. **Translations that come back with a different number of lines** than sentences sent (the translator merges or
   drops a line): the quiz and the translation view must not misalign; mismatched results drop the quiz to the
   aligned part or show a clear message. → `alignTranslations` test (Task 1).
4. **Few or near-identical sentences** (a story of 5 sentences, or two sentences with the same translation): the
   quiz never shows a question with fewer than 4 distinct choices, and with fewer than 4 usable sentences the
   quiz button is hidden. → `buildSentenceQuiz` tests (Task 1).
5. **Leaving the page or tapping New story while the model is loading or writing**: no result from the old run
   appears later, and the worker stops writing. → `useStoryWriter` cancel behaviour (Task 3, checked in the
   browser by the controller).

// pickStoryWords: only cards with an English word; distinct words (case-insensitive); at most n; all when fewer.
it("picks 12 distinct random words, or all of them when there are fewer", () => {
  const cards = Array.from({ length: 30 }, (_, i) => card(`w${i}`, `word${i}`)); // card(id, front) helper, src "en"
  const picked = pickStoryWords(cards);
  expect(picked).toHaveLength(12);
  expect(new Set(picked.map((w) => w.word)).size).toBe(12);
  expect(pickStoryWords(cards.slice(0, 5))).toHaveLength(5);
  expect(pickStoryWords([card("a", "Cat"), card("b", "cat")])).toHaveLength(1);
});
it("is random but follows the random source", () => {
  const cards = Array.from({ length: 30 }, (_, i) => card(`w${i}`, `word${i}`));
  const seq = (seed: number) => () => (seed = (seed * 9301 + 49297) % 233280) / 233280;
  expect(pickStoryWords(cards, 12, seq(1))).toEqual(pickStoryWords(cards, 12, seq(1)));
  expect(pickStoryWords(cards, 12, seq(1))).not.toEqual(pickStoryWords(cards, 12, seq(2)));

// "Title:" on the first line.
it("asks for a titled story using every word", () => {
  const [system, user] = storyPrompt(["apple", "thank you"]);

  expect(user.content).toContain("apple");
  expect(user.content).toContain("thank you");
  expect(user.content).toMatch(/Title:/);
});
// cleanStory
const STORY = "Title: A Day at the Market\n\nTom goes to the market. He buys an apple. It is red.\n\n" +
  "He sees his friend Ana. She says hello. They walk home.\n\nAt home, Tom eats the apple. It is sweet. " +
  "He is happy.";
it("reads a titled story", () => {
  expect(cleanStory(STORY)).toEqual({

      "Tom goes to the market. He buys an apple. It is red.",

it("drops chat lines, markdown, think blocks and word lists around the story", () => {
  const reply = "<think>\nok\n</think>\nSure! Here is your story:\n\n**Title: A Day at the Market**\n\n" +
    STORY.split("\n\n").slice(1).join("\n\n") + "\n\nWords used: apple, market, friend\n- apple\n- market";
  expect(cleanStory(reply)?.title).toBe("A Day at the Market");
  expect(cleanStory(reply)?.paragraphs).toHaveLength(3);
  expect(cleanStory(reply)?.paragraphs.join(" ")).not.toMatch(/Words used|Sure|\*\*/);
});
it("gives a story without a title line a title from its first words", () => {
  expect(cleanStory(STORY.replace("Title: A Day at the Market\n\n", ""))?.title).toBeTruthy();
});
it("rejects replies that are not a story", () => {
  expect(cleanStory("Sure! What kind of story would you like?")).toBeNull();     // too short
  expect(cleanStory("- apple\n- market\n- friend\n- hello\n- home\n- red\n- sweet\n- happy")).toBeNull(); // a list
  expect(cleanStory("Il était une fois un garçon. Il va au marché. Il achète une pomme. Elle est rouge. " +
    "Il voit son amie. Elle dit bonjour. Ils rentrent. Il mange la pomme.")).toBeNull(); // not English
  expect(cleanStory("")).toBeNull();
});
// storySentences / isCleanStory
it("splits each paragraph into sentences", () => {

});
it("rejects a story with an unsuitable word in any sentence or the title", () => {
  const s = cleanStory(STORY)!;
  expect(isCleanStory(s)).toBe(true);
  expect(isCleanStory({ ...s, paragraphs: [...s.paragraphs, "Then he saw a gun."] })).toBe(false);
  expect(isCleanStory({ ...s, title: "The killer" })).toBe(false);
});
// wordsInStory: word forms count (Review Focus 2)
it("counts other forms of a word as used", () => {
  const words = [{ id: "1", word: "go" }, { id: "2", word: "child" }, { id: "3", word: "thank you" }, { id: "4", word: "zebra" }];
  const story = { title: "Thank you", paragraphs: ["The children went home.", "She goes there."] };
  const { used, missed } = wordsInStory(story, words);
  expect(used.map((w) => w.id).sort()).toEqual(["1", "2", "3"]);

  expect(alignTranslations(["A.", "B."], " Un. \n\n Deux. ")).toEqual(["Un.", "Deux."]);
  expect(alignTranslations(["A.", "B."], "Un. Deux.")).toBeNull();
  expect(alignTranslations(["A.", "B."], "Un.\n\n")).toBeNull();

// buildSentenceQuiz (Review Focus 4)
it("asks up to 8 sentences with 4 distinct choices from the same story", () => {
  const en = Array.from({ length: 12 }, (_, i) => `Sentence number ${i} is here.`);
  const fr = en.map((_, i) => `Phrase numéro ${i} ici.`);
  const quiz = buildSentenceQuiz(en, fr);
  expect(quiz).toHaveLength(8);
  for (const q of quiz) {
    expect(q.choices).toHaveLength(4);
    expect(q.choices).toContain(q.answer);
    expect(fr[en.indexOf(q.sentence)]).toBe(q.answer);
    expect(q.choices.every((c) => fr.includes(c))).toBe(true);
  }
  // Story order is kept.
  expect(quiz.map((q) => en.indexOf(q.sentence))).toEqual([...quiz.map((q) => en.indexOf(q.sentence))].sort((a, b) => a - b));
});
it("never asks with fewer than 4 different choices", () => {
  expect(buildSentenceQuiz(["A b c.", "D e f.", "G h i."], ["Un.", "Deux.", "Trois."])).toEqual([]);
  const quiz = buildSentenceQuiz(["One two three.", "Four five six.", "Seven eight nine.", "Ten eleven twelve.", "More words here."],
    ["Pareil.", "pareil", "Trois.", "Quatre.", "Cinq."]);
  for (const q of quiz) expect(new Set(q.choices.map((c) => c.toLowerCase().replace(/\W/g, ""))).size).toBe(4);
});

    left.

### Task 1b: Write the story one sentence per word (added after the gate)

The gate (Task 2) showed that the model drops about half of a 12-word list when asked for the whole story at once
(6.0 of 12 words used), but uses 8.4 of 12 when the story is written one sentence per word. So the story is
written step by step.

**Files:**
- Modify: `src/lib/ai-story.ts`

**Interfaces:**
- Produces (in `src/lib/ai-story.ts`):
  - `export type Generate = (messages: ChatMessage[], maxNewTokens: number) => Promise<string | null>` (null means
    cancelled)
  - `export const SENTENCE_TOKENS = 48; export const TITLE_TOKENS = 16; export const MIN_STORY_SENTENCES = 8;`
  - `export function sentencePrompt(storySoFar: string[], word: string | null): ChatMessage[]`
  - `export function titlePrompt(sentences: string[]): ChatMessage[]`
  - `export function firstSentence(reply: string): string`
  - `export function isMetaSentence(sentence: string): boolean`
  - `export async function writeStory(words: StoryWord[], generate: Generate, onSentence?: (done: number, total:
    number) => void): Promise<string | null>` — returns the story as `Title: <title>\n\n<paragraphs>` (fed to
    `cleanStory`), or null when `generate` returned null (cancelled).
- `storyPrompt` stays (unused by the app) or is removed; nothing else uses it.

- [ ] **Step 1: Implement**, with these pinned choices (they are what the gate ran):
  - System message for every step: "You write short, simple stories in easy English (level A2) for language
    learners. The stories are friendly and suitable for children. Reply with the sentence only."
  - `sentencePrompt([], w)`: `Write the first sentence of a short, simple story for children. It must use the word
    "<w>". One short sentence.`; with a story so far: `Here is the story so far:\n<sentences joined by
    spaces>\n\nWrite the next sentence of this story. It must use the word "<w>". One short, simple sentence that
    continues the story.`; with `word` null (padding): the same without the "It must use the word" sentence.
  - `titlePrompt`: system "Reply with the title only."; user `Give this story a short title of 2 to 5
    words:\n<sentences joined by spaces>`.
  - `firstSentence`: drop `<think>…</think>`, `*`, `_`, `#`, straight and curly double quotes; first line; first
    sentence by `Intl.Segmenter("en", { granularity: "sentence" })`; trimmed.
  - `isMetaSentence`: true when the sentence talks about the task instead of the story — e.g. it contains (case
    insensitive) "I can't", "I cannot", "I'm sorry", "as an AI", "sentence", "the word", "your request", "here is",
    "here's", "story so far", or a blank like `__1__`; also true for an empty sentence.
  - `writeStory`: for each word, up to 2 attempts with `generate(sentencePrompt(done, word), SENTENCE_TOKENS)`; a
    sentence is accepted on the first attempt only if it is not meta, passes `isCleanSentence` and contains the word
    (by `wordsInStory`); on the second attempt it is accepted if it is not meta and passes `isCleanSentence` (even
    without the word); otherwise the word is skipped. Then, while fewer than `MIN_STORY_SENTENCES` sentences, add
    padding sentences (`word` null, same acceptance minus the word check, at most 2 attempts each, stop after 4
    failed attempts in a row). Call `onSentence(done.length, target)` after each accepted sentence, where target is
    `max(words.length, MIN_STORY_SENTENCES)`. Title: `generate(titlePrompt(done), TITLE_TOKENS)` →
    `firstSentence`, strip a leading `Title:` and a final `.`; if it has more than 6 words, contains "story" or
    "title", or is meta or fails `isCleanSentence`, use the first 4 words of the story instead. Paragraphs: the
    sentences in 3 near-equal groups (fewer when there are fewer than 3 sentences). Any null from `generate`
    returns null at once.
- [ ] **Step 2: Check.** `npx tsc --noEmit`, `npm run lint` pass. The controller re-runs the gate with `writeStory`.
